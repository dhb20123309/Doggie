# 需求文档

## 1. 改动目标
一句话：修复五子棋点棋盘没反应的 bug；相册上传支持一次多选批量导入；会话左下角工具箱新增「发送表情包」入口。

## 2. 现状 vs 目标
| 项 | 现状 | 目标 |
|---|---|---|
| 五子棋落子 | 点击棋盘任何格子都没有反应，无法下棋 | 人类回合点空位即落子，AI 正常应招 |
| 相册导入 | 文件选择框一次只能选一张，选完即入库一条 | 一次可勾选多张，全部读入后按时间顺序一次性入库 |
| 工具箱菜单 | 已有发送图片/转账/定位/开场白/档案/导入/游戏大厅等条目，无表情入口 | 新增「表情包」条目，点开弹出本角色可用表情网格，点选即以本人身份发出该表情消息（刷新不丢），并沿用现有"发图后 TA 会接话"的回复链路体验 |

## 3. 改动点说明
- **五子棋 bug 根因（已定位）**：通用棋盘点击匹配函数只认 `from`/`to` 两种坐标字段，而五子棋（含井字棋、四子连珠等同为单点落子的玩法）的合法动作是 `{ kind:"put", n:索引 }` 格式——匹配永远失败，所以点了没反应。修复方式：给点击匹配补上"单点索引 n 换算行列"的判定分支，一处修复覆盖所有同类玩法。
- **相册批量上传**：数据层增加批量添加接口（一批 url 一次性写入、各自独立 id 与时间戳）；相册导入的文件选择框加多选属性，选中后逐张读取转存、全部完成后一次写入并给出"已导入 N 张"反馈；相机拍照链路不动（仍是单张）。
- **工具箱发表情**：工具箱菜单加一个表情条目 → 弹出表情选择浮层（复用现有表情库数据与渲染样式，展示全局表情+该角色专属表情）→ 点选后以用户身份生成一条表情消息上屏并持久化。顺带修一个现存隐患：聊天页顶栏「表情」面板的发表情路径此前未直写存储（刷新可能丢失），本次统一改为即时落库。

## 7. 验收标准
1. 打开游戏大厅 → 五子棋开局，轮到"你"时点棋盘任意空位，棋子立即出现且 AI 在约一秒内应招；连续下到连五能正常判胜负。
2. 顺手验证井字棋、四子连珠、黑白棋仍可正常点击落子；中国象棋仍是"先点自己的子、再点目标格"两步操作。
3. 相册 → 导入，一次长按多选 3 张照片，确认后相册直接多出 3 张（按拍摄时间排列），无需重复点导入。
4. 相机拍一张仍能正常入相册。
5. 聊天页左下角工具箱出现「表情包」条目；点开能看到表情网格（含全局与该角色专属）；点任一个，气泡位置显示该表情图；退出聊天页再进来，这条表情还在；TA 会像收到普通消息一样对表情作出符合人设的回应。
6. 顶栏「表情」页里点表情发送同样即时落库（刷新不丢）。
7. `pnpm run build` 与类型检查全绿，预览无白屏无报错。

## 8. 不改动范围
- 五子棋引擎规则本身（duel-engine.ts 的胜负判定/AI 算法）不动；
- 其他 30 款玩法逻辑不动（cellMatch 修复属兼容性增强）；
- 壁纸/聊天背景/档案封面等其他单图上传入口保持现状（本次只按需求改相册）；
- 表情库管理（上传/命名/绑定角色）与模型侧 `[表情:名字]` 解析协议不动。
