# OpenAI发布GPT-Image-2.6提速50%

 2026-11-05 19:28 复制链接 

时间：2026年11月4日 地点：美国 人物：OpenAI 事件详情：OpenAI 于11月4日上线新一代图像生成模型 Images 2.6，API 侧对应 GPT-Image-2.6，并同步开放给 ChatGPT、ChatGPT Work 和 Codex，覆盖网页版、桌面版、手机版和全部订阅档位。API 端首次拆出两个型号：GPT-Image-2.6 Flare 主打速度与排版，低画质档下单张最快约6秒出图；GPT-Image-2.6 Sunburst 主打细节与多轮编辑一致性，在中高质量档下更不容易出现人物、商品和品牌细节漂移。OpenAI 称 Images 2.6 的图像生成速度比上一代 Images 2.5 提升50%。API 侧同时新增三项能力：图像标记（image markup）此前只有 ChatGPT 网页端可用，现在开放给 API；原生支持导出 SVG 矢量图；新增 complexity 参数，把场景规划与画质渲染拆开，complexity 控制模型动笔前投入的规划算力，quality 只负责视觉细节与保真度。 背景：Flare 和 Sunburst 这两个 API 档位并非这次才出现。The Decoder 指出，两者最早随 Images 2.5 一同推出，2.6 是在同一套双档结构上做的提速迭代。GIF 的实现路径同样不是走视频模型：C114 转载的36氪文章披露，官方给出的 OpenArt 合作案例提示词要求模型生成一张3列2行、共6帧的序列图（sprite sheet），再切片合成 GIF，这样既绕开了视频扩散模型高昂的推理延迟，又能保证每帧角色的五官、衣物与背景相对固定。 影响：对开发者而言，这次更新最有价值的一面在 API 侧——速度和精度第一次成为可选项，而不是同一个模型的单一档位。complexity 与 quality 解耦之后，日常改背景、换配色这类局部修改可以把 complexity 调低、保留高画质输出，省掉模型重新规划构图的时间；SVG 直出和图像标记开放给 API，则让生成的位图能直接进入网页、App 和印刷流程，Codex 里的前端开发也可以直接产出可无限缩放的图标和插画。定价上，据 TechNews 援引 OpenAI 定价页，Flare 与 Sunburst 同价，生成图片每百万 token 30美元、输入参考图片每百万 token 8美元、输入文字每百万 token 5美元，与上一代 Images 2.5 持平。规模上，OpenAI 称 ChatGPT 与 API 合计每周生成图像已超过40亿张，而八周前 Images 2.5 发布时这个数字是30多亿张。 总结：Images 2.6 真正的变化在 API 侧：双档模型把快与精显式拆开，complexity 参数把规划和渲染解耦，SVG 与图像标记把生成结果接进了工程链路，而价格没有随提速上调。中文开发者的选型逻辑很直接——草稿、排版和多版本试错用 Flare，成品图和需要反复修改的角色、商品、品牌视觉用 Sunburst，日常微调优先把 complexity 调低。 常见问题： 问：GPT-Image-2.6 和 Images 2.5 有什么区别？ 答：官方称生成速度比 2.5 快50%，API 侧换成 Flare 和 Sunburst 两个型号，Flare 低画质档最快约6秒出图。 问：Flare 和 Sunburst 怎么选？ 答：Flare 主打速度与排版，Sunburst 主打细节与多轮编辑一致性；日常微调可把 complexity 调低、保留高画质。 参考来源：
