# 需求文档

## 视觉风格

- **风格参考来源**：用户本轮明确指定的"奶油白毛玻璃 + 暖淡黄淡系"方向，延续现有 iOS 拟真手机外壳与果冻按压动效。
- **整体视觉取向**：由当前的冷调蓝紫浅色系整体转向暖淡黄色系——背景、卡片、气泡统一为奶油/黄油色调；毛玻璃质感保留但底色从纯半透明白改为奶油白（微黄），文字只做轻微加深以保证可读，不出现高对比黑字；聊天气泡为大圆角奶油浅透毛玻璃卡片配柔和淡阴影、去掉粗边框；头像旁加在线状态小绿点，AI 回复时显示三点跳动"正在输入中"，每条消息下方带小号浅灰时间戳。信息密度与布局结构不变，只换色彩与质感层。
- **受影响页面/区块**：全局配色 token（styles.css）、桌面时间/音乐小组件与 App 名/Dock、短信聊天页（背景、气泡、头像、输入状态、时间戳）、设置页壁纸区（新增聊天背景上传项）、旧版聊天页同步样式。锁屏数字键压暗层不受影响（白色文字在深色遮罩上仍清晰）。

## 已完成基础上的本轮改动目标

在不动任何业务逻辑（接口请求、localStorage、世界书、表情包、发送习惯、角色互动）的前提下，把虚拟手机整体换成"暖淡黄奶油毛玻璃"风格，并给聊天页补齐四项体验细节：可上传聊天背景、头像在线状态圆点、正在输入中三点动画、每条消息浅灰时间戳。

## 现状 vs 目标

| 项 | 当前 | 改后 |
|---|---|---|
| 全局配色 | 冷调蓝紫（background/primary/muted 均为 hue 265-275） | 暖淡黄（hue 约 75-90），深色列同步微调 |
| 桌面小组件 | glass 半透明白 + 纯白文字 | 奶油白毛玻璃（glass 底色微黄化），文字仅轻微加深保证可读 |
| 聊天气泡 | 用户=实心 primary 蓝紫、TA=bg-secondary，小圆角尾巴 | 两侧均为大圆角奶油浅透毛玻璃卡片、柔和淡阴影、无粗边框；用户侧用暖黄稍深一档区分左右 |
| 聊天背景 | 硬编码蓝紫渐变 | 支持用户上传替换（默认一张暖奶油渐变），未上传时用内置默认 |
| 头像 | 无状态标识 | 头像右下角小圆点：在线绿 / 回复中黄 / 未配置接口灰 |
| AI 生成中 | 已有三点 + "正在回复…"文案 | 保留三点动画，样式并入新气泡卡片（即"正在输入中"效果） |
| 时间戳 | ChatEntry.at 已存但未显示 | 每条消息下方显示小号浅灰 HH:MM（同一天相邻消息可合并显示，跨日显示日期+时间） |

## 改动点说明

1. **暖色设计系统**（styles.css）：`:root` 与 `.dark` 的 background/primary/secondary/muted/border/card 等 token 从蓝紫色相迁移到暖淡黄；`.glass`/`.glass-strong` 底色由纯白半透明改为奶油白半透明（微黄），阴影颜色同步转暖；新增两个聊天专用类：气泡奶油毛玻璃卡片、消息时间戳浅灰小字。
2. **桌面组件**（HomeScreen.tsx）：时间/音乐小组件继续用 glass（自动获得奶油底），文字从纯白改为轻微加深的暖深色以保证可读；App 名、Dock 标签同步微调；图标 tint 渐变为暖色系重排（保留辨识度）。
3. **聊天气泡**（RoleChatApp.tsx 的 Bubble 组件）：左右两侧均改为大圆角奶油浅透毛玻璃卡片 + 柔和淡阴影，去掉实色底和粗边框；用户侧比 TA 侧深一档暖黄以区分方向。
4. **聊天背景上传**：按锁屏/桌面壁纸同款链路新增"聊天背景"——lock-store.ts 增加 useChatBackground（key vp-phone:chat-bg:v1，默认内置暖奶油渐变图）；SettingsApp 壁纸区加第三个选择器；PhoneShell 取值并传给聊天页；RoleChatApp 顶部容器由硬编码渐变改为读取该背景。
5. **在线状态圆点**（RoleChatApp.tsx 的 Avatar 组件）：头像右下角叠加小圆点，颜色由现成的 pending/ready 状态推导（回复中琥珀 / 在线绿 / 未配置灰），不新增数据字段、不改 Character 类型。
6. **正在输入中**：pending 时的三点气泡套用新奶油毛玻璃卡片样式，视觉上与消息气泡一致，形成"对方正在输入"观感。
7. **消息时间戳**：渲染每条消息时读取已有的 entry.at 格式化为浅灰小字（纯展示层，数据早已存储，零逻辑改动）。
8. **旧版聊天页同步**（ChatApp.tsx）：气泡样式类同步替换，保持两套界面观感一致。

## 影响面与调用链

```
styles.css (token/glass 类) ──► 全部屏幕自动换肤
lock-store.useChatBackground ──► PhoneShell ──┬──► SettingsApp(上传替换)
                                              └──► RoleChatApp(聊天背景层)
ChatEntry.at (已有数据) ──► RoleChatApp/ChatApp 渲染层 ──► 时间戳显示
pending/ready (已有状态) ──► Avatar 圆点颜色 ──► 顶栏 + 每条 TA 消息头像
```

## 回归与兼容风险

| 风险点 | 是否破坏现有行为 | 兼容策略 | 回归测试点 |
|---|---|---|---|
| 全局 token 换色 | 否（纯样式） | 保留 .dark 一套同步改 | 各页面文字对比度、连接测试结果卡成功/失败配色 |
| 气泡改毛玻璃 | 否 | 仅改 Bubble 组件 class | 多气泡拆分、表情图片气泡、旁白区分仍正确 |
| 新增聊天背景 key | 否 | 老用户无该 key 时回退默认图 | 上传→刷新→仍生效；删除不影响其他壁纸 |
| Avatar 加圆点 | 否 | 绝对定位叠加，尺寸参数不变 | 顶栏/消息行/编辑页三处头像均正常 |
| 时间戳展示 | 否 | 只读已有 at 字段 | 历史消息（无异常 at）不报错 |
| 接口/世界书/表情/发送习惯 | 否 | 相关文件零改动 | 连接测试、发送、重试、自动生成倒计时 |

## 涉及文件定位

- `src/styles.css`：`:root`/`.dark` token、`.glass`/`.glass-strong`、新增气泡与时间戳类
- `src/components/HomeScreen.tsx`：小组件文字色、图标 tint
- `src/components/RoleChatApp.tsx`：Bubble、Avatar、pending 气泡、时间戳、聊天背景层
- `src/components/ChatApp.tsx`：旧版气泡同步
- `src/lib/lock-store.ts`：useChatBackground
- `src/components/SettingsApp.tsx`：WallpaperSection 第三选择器
- `src/components/PhoneShell.tsx`：背景值传递
- 素材：生成一张默认"暖奶油渐变"聊天背景图（CDN URL 作默认值）

## 验收标准

1. 打开页面直接是手机，整体呈暖淡黄色调，无蓝紫残留（锁屏数字键盘除外区域正常）。
2. 桌面时间/音乐小组件为奶油白毛玻璃，文字清晰可读。
3. 输入 0517 解锁 → 进短信：聊天气泡为大圆角奶油毛玻璃卡片、无粗边框、阴影柔和；每条消息下有浅灰小时间戳。
4. TA 头像右下角有状态圆点；发送后等待回复期间出现三点跳动的"正在输入中"气泡。
5. 设置 → 壁纸区出现"聊天背景"上传项，换图后聊天页背景立即替换且刷新后保留。
6. API 配置、连接测试、世界书、表情包、四种发送模式、聊天记录持久化全部与改造前一致。

## 不改动范围

- ai-api.ts / worldbook.ts / config-store.ts / chat-types.ts 等业务核心零改动
- 锁屏密码校验逻辑、解锁动画、桌面 Dock 结构
- 未读红点/角标相关既有逻辑（保持原样）
- 相机/相册/记忆中枢/音乐壳应用的功能逻辑（仅随全局 token 自然换色）
