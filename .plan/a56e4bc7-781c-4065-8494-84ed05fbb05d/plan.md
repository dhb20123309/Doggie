# 需求文档

## 1. 应用概述
- **应用名称**：Companion OS · 虚拟伴侣桌面（在现有「浏览器虚拟小手机」内升级）
- **应用描述**：把现在的小手机升级成一套「暖奶油淡黄 + 轻拟物萌系极简」的虚拟伴侣系统：仿真手机外壳（灵动岛、状态栏、手势横条），主屏为双屏横向滑动轮播——第一屏是陪伴主屏（大时钟胶囊、主角头像底座、日记预览条、音乐播放胶囊、5 个功能 App），第二屏是生活小组件 Bento 屏（番茄钟、今日天色、随写便签、心事短句）。底部常驻悬浮玻璃 Dock（相册/消息/设置）。保留你已接入的全部真实能力：API 聊天、主动消息、生图照片、世界书、表情包、TTS 朗读、音乐真机播放。

## 2. 用户与使用场景
- **目标用户**：想要一个"住在浏览器里的 AI 伴侣"的你本人。
- **核心使用场景**：
  - 解锁后看到双屏桌面，左右滑动切换，看时间、问候、TA 的最新日记；
  - 在桌面直接写便签（自动保存）、开番茄钟（TA 陪读）、看天气组件；
  - 点「消息」和周晨砚/周风砚聊天（沿用现有全部聊天能力）；
  - 玩「查手机」彩蛋（翻 TA 的秘密草稿、搜索记录、私密相册）、「心动羁绊」（纪念日倒计时）、「小剧场」（分支剧情阅读）；
  - 「设置」里配置 API、密码、壁纸、生图/语音/音乐通道（现有功能全保留）。

## 4. 业务规则与逻辑
- **双屏轮播**：触控左右滑动、PC 鼠标拖拽、指示点点击三种方式切换，动画丝滑跟手；
- **问候语**：按时段变化（凌晨/早上/下午/晚上好，{昵称}）；
- **日记**：角色按人设生成短随笔（复用聊天 API，失败回落模板池），存入本地；桌面预览条始终显示最新一条；
- **查手机**：内容围绕当前活跃角色动态生成（锁屏电量、隐秘搜索记录、未发草稿箱、私密相册位），一次生成后本地留存，可下拉刷新；
- **心动羁绊**：从首次聊天日起累计恋爱天数 + 手动设置的纪念日/生日倒计时；
- **偏好记忆**：可让模型从聊天记录提炼"TA 观察到的你的习惯"列表，也可手动增删；
- **小剧场**：内置 1-2 个周氏双子分支剧本（选项驱动走向），纯本地文本引擎，不耗 API；
- **番茄钟**：真实秒级倒计时，结束时若配好 API 请角色发一句鼓励进消息会话；
- **消息**：完全沿用现状——多角色会话列表、自动回复、主动消息、照片自发、表情、朗读、未读角标。

## 5. 异常与边界情况
| 场景 | 处理方式 |
|------|----------|
| 未配置 API | 日记/查手机/偏好提炼显示"需要先连接大脑（去设置）"提示，其余本地功能不受影响 |
| 生成请求失败 | 回落到本地模板池内容，不白屏不报错弹窗 |
| 便签超长 | 限制 2000 字并显示字数统计 |
| 无音频直链 | 音乐胶囊显示演示曲目、点击提示去设置填音源 |
| 双屏快速滑动 | 边缘阻尼，不会滑出第三屏空白 |

## 6. 验收标准
- 解锁后默认停在屏1，左右滑动/拖拽/点指示点均可切屏；
- 屏1 头像底座干净无侧边文字，点头像进个人资料可改称呼；
- 屏2 四张卡片齐全，便签输入后刷新页面内容仍在；
- 番茄钟切换时长、倒计时、暂停/重置正常；
- 5 个新图标逐个可进入且功能可用；Dock 三键平齐、发消息后红点出现、进会话消失；
- 原有聊天全流程（发送、自动回复、主动消息、照片、表情、朗读）回归正常。
