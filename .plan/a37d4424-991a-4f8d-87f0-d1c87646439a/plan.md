# 需求文档

## 1. 应用概述
- **功能名称**：双弈棋盘 —— 和 TA 下棋（内置版）
- **描述**：在虚拟手机里新增一个"下棋"入口，用户可以直接和恋爱角色下中国象棋与五子棋。棋盘在手机屏幕上完整呈现，走子、悔棋、认输、胜负结算全部在网页内完成，不依赖电脑上的任何服务——真机随时能玩。AI 角色的棋力由本地算法驱动，同时会像真人一样在聊天里对棋局发表感想（赢了得意、输了嘴硬）。

## 2. 用户与使用场景
- 目标用户：想在聊天之外和角色有互动玩法的玩家
- 核心场景：
  - 打开某个角色的聊天页 → 工具箱点「下棋」→ 选象棋或五子棋 → 直接开一局
  - 手机上用点按方式走棋：先点自己的棋子（显示合法落点），再点目标格
  - 下到一半退出，下次进来棋局还在（可继续/可重开）
  - 终局后角色在会话里发一条与棋局结果相关的消息（连输三局会不服气之类）

## 3. 页面结构与功能说明
- 页面结构：
  ```
  手机壳
   ├─ 聊天页工具箱 → 新增「下棋」入口
   └─ 对局全屏页（新 ScreenId: duel）
        ├─ 顶栏：角色头像+名字 ｜ 游戏名 ｜ 认输/重开按钮
        ├─ 棋盘区：五子棋 15×15 网格 / 象棋 9×10 交叉线棋盘
        ├─ 状态条：轮到谁、思考中动画、将军提示
        └─ 底部：悔棋按钮 + 提和按钮
  ```
- 交互说明：
  - **五子棋**：玩家执黑先行，点击交叉点落子；角色方有约 0.8~2 秒"思考"延迟再落白子，期间棋盘上方显示"TA 在琢磨…"
  - **象棋**：玩家执红先行；点棋子高亮其所有合法着法（小圆点标记），点目标格完成走子；被"将军"时状态条红字提示；吃掉的子陈列在棋盘两侧
  - **悔棋**：一次撤销双方各一手，每局限 3 次
  - **认输/提和**：认输直接判负；提和由角色按局势决定接受与否（大优时会拒绝并阴阳怪气）
  - 终局弹出结果卡（胜/负/和 + 战绩累计），关闭后回聊天页

## 4. 业务规则与逻辑
- **棋类规则引擎**：纯前端 TypeScript 实现
  - 五子棋：标准连五判定（含禁手不做，简单规则）
  - 象棋：完整走法规则（马腿、象眼塞田、炮隔山打、九宫、过河兵、将帅照面、送将禁止）、将军/将死/困毙判定、60 回合自然限着判和
- **AI 棋力**：
  - 五子棋：防守+进攻启发式评分（活四/冲四/活三打分，优先成杀再破杀）
  - 象棋：浅层搜索（2 层 alpha-beta）+ 子力位置价值评估，强度定位"会玩但常犯错"的恋人水平
- **战绩与情绪联动**：每个角色分别记录 胜/负/和 场次；连败 3 局后角色主动消息池加入"再来一局！这次让你三个车"类句式；连胜时加入炫耀句式
- **终局聊天反馈**：对局结束后自动让角色在对应会话发一条主动消息（引用本局结果，走现有主动消息链路生成）
- **持久化**：进行中棋局与战绩存 localStorage（key `vp-phone:duel:*`），刷新/退出恢复

## 5. 异常与边界情况
| 场景 | 处理方式 |
|---|---|
| 棋局下到一半切换角色 | 棋局按角色 id 隔离存储，切回可继续 |
| 走非法着法 | 根本不可点（只允许点合法目标），无报错路径 |
| 悔棋次数用完 | 按钮置灰并提示"这局就剩这一次机会都不给你了" |
| AI 思考期间用户退出 | 落子照常写入棋局，回来看到最新盘面 |
| 存储损坏/数据异常 | 视为无局可续，静默重开新局 |

## 6. 验收标准
- [ ] 聊天页工具箱出现「下棋」入口，点击可选象棋/五子棋
- [ ] 五子棋：能落子、AI 应招、连五即终局弹结果卡
- [ ] 象棋：红方先行，点子显合法点、只能走合法着；被将军有提示；将死后终局
- [ ] 悔棋、认输、重开均可用；战绩在个人档案/角色名片处可见
- [ ] 终局后角色在聊天里发出与结果相符的消息
- [ ] 中途退出再进，棋局原样恢复
- [ ] 手机 H5 视口下棋盘完整可点，桌面机身模式同样正常
