# 需求文档

## 1. 改动目标
把「虚拟小手机」从"介绍页 + 手机演示"改造为**打开即用的纯手机体验**：删掉所有介绍文案，页面直接呈现居中的竖版拟真手机；新增锁屏密码流程；桌面、聊天、设置全面统一 iOS 毛玻璃（Frosted Glass）风格。

## 2. 现状 vs 目标
| 方面 | 当前 | 目标 |
|------|------|------|
| 首屏 | 大标题+介绍段落+要点列表，下方才是手机 | 无介绍文字，加载完成即居中显示竖版手机外壳 |
| 进入方式 | 直接是桌面 | 先进锁屏 → 数字密码校验通过才进桌面 |
| 视觉 | 深色渐变机身 + 蓝紫桌面 | 柔和 iOS 毛玻璃：backdrop-filter 磨砂、低饱和配色、柔和阴影、统一大圆角 |
| 桌面应用 | 设置 / AI助手 / TA的聊天 / 世界书 / 表情包 / 电话 / 相机 / 计算器 | 设置 / 短信(原TA的聊天) / 世界书(朋友圈入口) / 相册 / 相机 / 记忆中枢 / 音乐 + Dock 栏 |
| 小组件 | 仅时间日期卡 | 时间日期组件 + 音乐小组件 |
| 状态栏 | 简化版 | 还原 iOS：时间、信号格、Wi-Fi、电量图标 |
| 背景 | 固定壁纸 | 锁屏背景、桌面背景均支持用户上传替换 |

## 3. 功能说明（按页面）

### 锁屏页
- 全屏锁屏：大号时间/日期、上滑或点击唤起密码面板。
- 数字密码面板：0-9 圆形按键 + 删除键；顶部 4 个密码圆点指示器，输入即点亮。
- **初始固定密码 `0517`**；校验通过解锁进入桌面；错误时圆点抖动 + 「密码错误」轻提示，清空重输。
- 锁屏背景可自定义上传（默认内置柔和渐变壁纸）。

### 桌面
- 全局毛玻璃质感：图标、小组件、Dock 均为磨砂半透明卡片，统一大圆角。
- 桌面背景支持上传替换；长按不需要的旧占位 App（电话/计算器）移除。
- APP 图标：**设置、短信、世界书、相册、相机、记忆中枢、音乐**。
- 小组件：时间日期组件（现有逻辑保留）、音乐小组件（展示当前曲目/播放暂停按钮，本地演示级）。
- 顶部 iOS 状态栏（时间/信号/Wi-Fi/电量），底部 Dock 栏（放常用四App）。

### 锁屏密码管理
- 设置页新增「锁屏密码」区：输入旧密码验证后设置新密码（4-6 位数字），保存在浏览器本地；首次以 0517 为准。

### APP 内页面（业务逻辑不动）
- **短信（原「TA 的聊天」）**：微信式对话布局、旁白区分、消息红点+未读数字角标全部保留；API 请求、世界书、表情包、发送习惯、重试等逻辑零改动，仅换肤。
- **设置**：接口地址、API Key、模型名、连接测试、拉取模型列表、温度滑杆全部保留，密钥依旧只存本地；新增锁屏密码修改项。
- **世界书**：沿用现有全局/局部绑定与拼接逻辑，界面换毛玻璃皮肤，作为"朋友圈"式信息流入口呈现设定条目。
- **相册 / 相机 / 记忆中枢 / 音乐**：新增轻量壳应用——相册展示用户上传的图片（含锁屏/桌面背景来源）；相机提供取景框+拍照存入相册（本机模拟）；记忆中枢汇总本机存的聊天记录条数、角色、世界书、表情数量等统计；音乐小组件的完整播放列表页（本地演示曲库，不接真实音源）。

## 4. 视觉风格（本次重点）
- **参考调性**：iOS 26 Liquid Glass / 毛玻璃拟态——通透、轻盈、克制。
- **取向**：低饱和灰白+淡彩点缀的配色；大面积 backdrop-blur 磨砂层叠；柔和弥散阴影；统一 20px+ 大圆角；字体纤细现代；信息密度低、留白充足。
- **受影响范围**：手机外壳、锁屏、桌面、状态栏、Dock、小组件、短信、设置、世界书及四个新壳应用；外层网页背景改为柔和渐变衬托居中手机。
- 最终生效风格由你在计划确认卡的风格设计中从多套方案里选定。

## 5. 交互动画
- 锁屏解锁：密码正确后锁屏上滑淡出，桌面缩放浮现。
- 打开 App：图标放大铺满屏幕（iOS 经典 zoom）；关闭：缩回图标位置。
- App 间切换、页面进出均有平滑过渡；手机外壳保持固定比例（9:19.5）随窗口自适应居中。

## 6. 影响面与调用链
```
index.tsx(装配) ─► PhoneShell(外壳/路由壳)
                    ├─► [新增] LockScreen(密码校验 ◄─ lock-store)
                    ├─► HomeScreen(桌面/图标/Dock/小组件)
                    ├─► SettingsApp(原有功能 + [新增]改密码)
                    ├─► RoleChatApp(短信：逻辑不动，仅换肤)
                    ├─► WorldBookApp(换肤)
                    └─► [新增] Album/Camera/Memory/Music 壳应用
ai-api / chat-store / worldbook / config-store ── 不改动
```

## 7. 验收标准
1. 打开页面：无任何介绍文字，直接看到居中竖版手机，先显示锁屏。
2. 锁屏输入 0517 → 动画解锁进桌面；输错有抖动提示。
3. 设置页修改密码后回锁屏，旧密码失效、新密码可解锁；刷新浏览器仍是新密码。
4. 锁屏和桌面分别上传一张图，两处背景立即替换且刷新后保留。
5. 桌面可见 7 个 App + 时间日期/音乐两个小组件 + iOS 状态栏 + Dock。
6. 短信里发消息、世界书/表情包/发送习惯、设置里连接测试等原有功能行为不变。
7. 点开/退出任意 App 有缩放过渡动画，窗口缩放时手机保持比例居中。

## 8. 不改动范围
- 接口请求层（候选地址、拉模型、报错翻译）、localStorage 存储结构、聊天核心逻辑（气泡拆分、倒计时自动回复、四种发送模式、重试）、世界书拼接与表情解析、API Key 本地存储策略。
- 不引入 Redis/队列/独立后端等新架构；不新增引导文案。
